# 日本防衛データ（仮）

日本の防衛と防衛産業について、予算・契約・企業・装備・人事・政策・輸出・周辺国の動きを、公開資料と出典でつないだ非公式のまとめサイト。個人が運営している。

公開ページ: https://bouei-data.github.io/

## ファイル

| ファイル | 中身 | 更新 |
|---|---|---|
| `index.html` | サイト本体（データを埋め込んだ1枚のページ） | 手作業で作り直したとき |
| `news_auto.json` | ニュースの自動追加分 | 毎週月・木 |
| `people_auto.json` | 防衛省・自衛隊の主な人事 | 毎週火 |
| `contracts_auto.json` | 陸自補給本部・防衛装備庁の契約 | 毎週水 |
| `stats_auto.json` | スクランブル・予算・業績などの数字 | 毎月10日 |

ページは開いたときに `*_auto.json` を読み込んで、本体のデータに足して表示する。

## 守っていること

- 公開されている情報だけを使う。すべての数字に出典を付ける。
- 個人事業者の名前や住所は載せない。
- 株価は載せない。
